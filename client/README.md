# GeoHealth Insights Client

React client built with Vite and tested with Vitest.

## Commands

- `npm start` or `npm run dev`: start the development server.
- `npm test`: run the test suite once.
- `npm run test:watch`: run tests in watch mode.
- `npm run build`: create the production bundle in `build`.
- `npm run preview`: serve the production bundle locally.

## Environment

The preferred public client variables are `VITE_API_URL` and `VITE_MAPBOX_TOKEN`. The previous `REACT_APP_API_URL` and `REACT_APP_MAPBOX_TOKEN` names remain supported during the Render migration.
